# CV-Learning

> 本分支由 `master` `1e939d7aff47cc8c74d4770617282db09071ef02` 生成。内容修改请在主干完成。

本仓库整理计算机视觉与机器学习的理论知识和论文，重点关注 **分布偏移下的工业异常检测**：训练只使用正常样本时，如何在产品、相机或光照条件变化后，识别并定位未知缺陷。

基础部分介绍理解这些方法所需的深度学习与视觉知识；领域自适应部分讨论如何利用源域知识适应目标域。本库只收录理论文档、论文原文和正文引用的论文图片。

## 从哪里开始

先看 [学习路径](learning-path.md)，了解已有内容与待编写主题，再阅读两篇总览：

- [工业异常检测：问题设定与方法总览](03-%E7%BC%BA%E9%99%B7%E6%A3%80%E6%B5%8B/problem-setting-and-overview.md)：训练能使用什么数据，测试需要识别什么异常，各类方法依赖什么假设。
- [领域自适应：问题设定与方法总览](04-%E9%A2%86%E5%9F%9F%E8%87%AA%E9%80%82%E5%BA%94/problem-setting-and-overview.md)：源域与目标域是什么关系，适配时能使用哪些数据，迁移会怎样影响异常识别。

基础知识不足时，可从 [卷积](01-%E5%9F%BA%E7%A1%80%E7%90%86%E8%AE%BA/convolution.md)、[注意力](01-%E5%9F%BA%E7%A1%80%E7%90%86%E8%AE%BA/attention.md)和 [损失函数](01-%E5%9F%BA%E7%A1%80%E7%90%86%E8%AE%BA/losses.md)补起。学习路径中的链接区分已有正文、阅读草稿、仅有论文和待编写主题。

## 内容如何组织

| 目录                      | 内容                                                   |
| ------------------------- | ------------------------------------------------------ |
| `01-基础理论/`       | 深度学习基础，包括卷积、注意力、损失函数与参数高效微调 |
| `02-基础视觉任务/`      | 传统视觉、目标检测、图像分割、多模态与生成模型         |
| `03-缺陷检测/` | 工业光学异常检测的问题设定、方法族与综述       |
| `04-领域自适应/` | 领域自适应；先介绍问题设定，再按方法族组织             |
| `99-待分类/`             | 尚未归入上述领域的论文                                 |

**方法族**指基本建模思路相近的一组方法，例如记忆库与原型方法、对抗对齐方法。**主题串讲**围绕一个方法族或基础主题，连贯介绍问题、假设、公式及方法之间的关系，是本库公开正文的主要形式。

一篇论文对应一个目录，原文与书目信息分别保存在 `paper.pdf` 和 `sources.md` 中。论文旁的单篇精读仍按阅读草稿对待；目录中只有 `to-be-filled.md` 时，表示该主题尚未补充内容。

## 理论文档的写法

正文从具体问题出发，依次说明模型假设、数学定义和信息流。论文发现、业界共识、数学推导与分析判断分别标注；方法、公式和实验数据给出原始出处及页码。非通用英文缩写首次出现时，给出英文全称、中文翻译和一句话定义。
