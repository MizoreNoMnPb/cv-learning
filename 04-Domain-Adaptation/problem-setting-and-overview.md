# 领域自适应：问题设定与方法总览

本文先区分适配阶段能使用的数据，再介绍方法族及其与工业异常检测的关系。方法族的内容状态见 [学习路径](../learning-path.md)。

**[分析判断]** 工业异常检测中的适配需要处理正常的产品或采集条件变化，同时保留识别未知缺陷的能力。例如，相机变化引起的色差可以被适配，但新增划痕仍应被识别为异常。

本文用 **[论文发现]** 标注原文直接报告的内容，用 **[业界共识]** 标注常见设定，用 **[分析判断]** 标注应用到异常检测时的推断。

---

## 0. 领域自适应与相关设定

> DA（Domain Adaptation，领域自适应）：源域与目标域数据分布不同，但任务相关；适配阶段 **能看见目标域数据**（至少未标注）。
>
> DG（Domain Generalization，领域泛化）：训练时 **完全没有** 目标域样本，要在未见过的新域上工作。
>
> TTA（Test-Time Adaptation，测试时适应）：训练已结束，在 **测试当下** 用当前测试批次或数据流更新模型。
>
> SFDA（Source-Free Domain Adaptation，源数据不可用的领域自适应）：适配时没有源数据，只留源模型与目标未标注数据。

**[分析判断]** “使用未标注数据”还不足以确定任务属于领域自适应，需要说明源域与目标域的关系：

- 仅用目标产品的正常图像建立参考特征库，且没有源域迁移过程：可按目标域上的单类异常检测理解。
- 冻结视觉语言模型，直接用文本类别描述进行零样本识别：这一过程没有针对目标域数据进行适配。相关基础见 [CLIP](../02-Vision-Tasks/clip.md)。
- 平均教师方法利用教师与学生预测的一致性学习未标注数据。用于领域自适应时，还需要明确源域、目标域和各自的监督信息。

## 1. 问题设定

阅读论文时，先记录特征空间、监督信息、类别集合与预测任务，再分析具体方法。

### 1.1 域是否同质

| 设定 | 含义 |
|---|---|
| 同质领域自适应（Homogeneous DA） | 源域与目标域使用相同的特征空间；分布仍可以不同 |
| 异质领域自适应（Heterogeneous DA） | 源域与目标域的特征空间不同，例如使用不同模态的表示 |

类别集合是否相同是另一个问题，在第 1.3 节单独说明。

### 1.2 可用数据与监督信息

> UDA（Unsupervised Domain Adaptation，无监督领域自适应）：用有任务标签的源域数据和无任务标签的目标域数据进行适配。

| 名称 | 源域标签 | 目标域标签 | 适配时源数据 |
|---|---|---|---|
| UDA | 有 | 无 | 有 |
| 半监督 DA | 有 | 少量 | 有 |
| SFDA | 训练源模型时有 | 无 | **无**（只留模型） |
| 黑盒领域自适应（Black-box DA） | 源模型训练时通常有 | 无 | 常不提供源数据及模型权重，仅可查询源模型预测 |

领域泛化不使用目标域训练样本；测试时适应则在测试过程中使用当前数据。它们与上表的区别主要在数据可见性和更新时间，不能只按标签多少划分。

### 1.3 标签空间

| 类别关系 | 含义 |
|---|---|
| 闭集（Closed-set） | 源域与目标域的类别集合相同 |
| 部分集（Partial） | 目标域类别是源域类别的真子集 |
| 开放集（Open-set） | 目标域含源域未覆盖的未知类别；具体类别重叠条件需看论文协议 |
| 通用（Universal） | 不预先限定两域类别集合的关系，可能同时存在各域独有的类别 |

**[分析判断]** 未知缺陷需要被识别为异常。若分类器只能从固定的已知类别中选择一个输出，又没有额外的异常评分或拒识规则，未知缺陷就会被分到某个已知类。因此，类别对齐与异常拒识需要分别讨论。

### 1.4 任务对齐的是什么

| 任务 | 通常对齐什么 |
|---|---|
| 分类 | 全局特征、类别原型 |
| 检测 | 整图特征、候选区域特征，有时还有目标之间的关系 |
| 分割 | 输出空间、类别混合采样、教师伪标签 |

**[论文发现]** 领域自适应 Faster R-CNN 同时使用图像级与实例级的对抗对齐。[1，第 3–5 页] 领域对抗神经网络则通过域分类器与梯度反转学习表示。[2，第 10–12 页]

> DANN（Domain-Adversarial Neural Network，领域对抗神经网络）：让域分类器学习区分数据来源，同时让特征提取器降低这种区分能力，并保留任务所需的信息。[2]

### 1.5 用于工业异常检测时的额外约束

本库重点讨论同质、单源到单目标的适配：目标侧有一批确认正常的产品图像，测试时缺陷类型未知。“确认正常”本身提供了正常与异常的类别信息，应与普通 UDA 中目标样本完全没有任务标签的情况区分。

**[分析判断]** 比较具体方法时，还应说明以下条件：

- 若利用源域知识与目标正常样本进行适配，需要说明哪些特征或统计量可以迁移。
- 若适配数据中混入未知缺陷，需要检查缺陷是否被误当作正常样本更新。
- 若适配时只能保留源模型，不能访问源数据，还需考虑源数据不可用的约束。
- 若在测试过程中更新模型，需要检查异常样本对后续预测的影响。

本库同时关注正常变化能否被接受、未知缺陷能否被识别。选择对齐或自训练方法时，应说明它们分别会怎样影响这两个目标。

## 2. 方法族总览

**[分析判断]** 下表按现有目录概括方法的作用。部分分类存在交叉，目录不代表互斥的理论划分；内容是否可读以最后一列为准。

| 方法族入口 | 主要思路 | 内容状态与阅读提示 |
|---|---|---|
| [对抗方法](Adversarial/) | 训练域分类器，并让特征提取器降低域可区分性；也可结合共享与私有表示分解 | 已有论文及单篇草稿，串讲待编写 |
| [分布差异最小化](Discrepancy-Minimization/) | 显式减小两域表示的分布差异 | 待补充论文与串讲 |
| [对齐](Alignment/) | 对齐统计量或表示，与上一类有交叉 | 待补充论文与串讲 |
| [重建与解耦](Reconstruction-and-Disentanglement/) | 通过重建与表示分解区分共享信息和域特有信息 | 待补充论文与串讲；领域分离网络原文在对抗方法目录 |
| [生成方法](Generative/) | 用图像翻译改变样本外观 | 已有论文；图像翻译用于适配时仍需说明任务协议 |
| [融合与混合](Fusion-and-Mixing/) | 混合跨域样本或表示 | 已有论文；需分别检查每篇的监督条件 |
| [平均教师](Mean-Teacher/) | 平滑更新教师参数，以教师预测约束学生 | 已有论文；串讲需说明从半监督学习到领域自适应的变化 |
| [伪标签](Pseudo-Label/) | 用模型预测构造训练目标，进行自训练 | 已有论文，包含源数据不可用与黑盒适配的工作 |
| [新问题设定](New-Problem-Settings/) | 收集额外的数据约束与任务设定 | 已有部分论文；领域泛化与测试时适应安排在后续 |
| [视觉语言先验](VLM-Prior/pointer.md) | 引用预训练视觉语言表示 | 相关基础正文在视觉任务目录；此处提供跨主题入口 |
| [综述](Survey/) | 比较问题设定与方法分类 | 已有论文，用于查阅；综述本身不是方法族 |

### 2.1 阅读顺序与当前进度

1. 先读本文第 1 节，明确可用数据与预测目标。
2. 进入 [对抗方法](Adversarial/)，阅读领域对抗神经网络与领域分离网络的论文和草稿。
3. 再读 [平均教师](Mean-Teacher/)与 [伪标签](Pseudo-Label/)目录中的论文；对应串讲尚未完成。
4. 按任务需要查阅其他已有论文的方法族；仅有占位文件的主题暂时跳过。

## 3. 与异常检测的关系

**[分析判断]** 结合 [异常检测总览](../03-Anomaly-Detection/problem-setting-and-overview.md)中的域关系，分别回答：源域提供了什么知识，目标域提供了什么数据，适配后怎样计算异常分数。仅说明“源域与目标域的特征更相似”，还不足以解释缺陷为何可被识别。

低秩微调规定参数如何更新，视觉语言预训练提供表示基础；它们用于领域自适应时，仍需另外规定目标域学习协议。相关内容见 [低秩微调](../01-Foundations/PEFT/)和 [CLIP](../02-Vision-Tasks/clip.md)。
