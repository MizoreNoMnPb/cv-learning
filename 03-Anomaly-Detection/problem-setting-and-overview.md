# 工业异常检测：问题设定与方法总览

本文先说明训练数据、异常类型和域变化，再比较各类方法对正常样本的建模假设。方法族的内容状态见 [学习路径](../learning-path.md)。

本库关注这样的问题：训练只使用正常产品图像，测试时需要识别并定位未知缺陷，而且产品、相机或光照条件可能变化。**拒识**指将不符合正常样本特征的输入判为异常，而不强行归入正常类。

> AD（Anomaly Detection，异常检测）：根据参考数据建立正常样本的模型，并识别偏离正常模式的样本。
>
> DA（Domain Adaptation，领域自适应）：利用源域知识及适配时可获得的目标域数据，处理两个域之间的分布差异。

本文用 **[论文发现]** 标注论文直接报告的内容，用 **[业界共识]** 标注常见设定，用 **[分析判断]** 标注本文的方法比较与应用判断。

## 0. 比较方法前，先明确问题

**[分析判断]** “异常检测”覆盖多种数据与任务。只看方法名称，容易把不同实验条件下的结果放在一起比较。阅读时应先回答三个问题：

1. 训练数据是否全部正常，是否有缺陷标签？
2. 测试中的异常是局部缺陷、零件关系错误，还是整个物体类别改变？
3. 测试数据与训练数据的产品、相机或采集条件是否相同？

方法族说明“如何建模正常样本”，问题设定说明“模型能使用什么信息、需要识别什么变化”。两者需要分别记录。

## 1. 三类异常检测问题

> OCC（One-Class Classification，单类分类）：训练只观察一个类别，测试时识别偏离该类的样本。

| 问题 | 训练看见什么 | 「异常」是什么 | 典型文献 | 本库的阅读范围 |
|---|---|---|---|---|
| 语义单类分类（OCC） | 一个语义类的图像 | 其他语义类 | Tax & Duin, SVDD, 2004；Ruff et al., Deep SVDD, ICML 2018（MNIST/CIFAR） | 收进 `OCC/`，用于理解单类建模；工业图像还需要考虑局部缺陷定位 |
| 工业冷启动视觉 AD | 某产品的正常图像 | 未知缺陷（划痕、污渍、变形等），通常要像素定位 | Roth et al., PatchCore, CVPR 2022 | **主要研究对象** |
| 机械健康监测 | 健康工况的振动/传感器序列 | 部件故障 | Liu & Gryllias, PHM 2021 | 原文在收件箱；单类分类主题可作比较 |

> 出处：David M.J. Tax, Robert P.W. Duin. “Support Vector Data Description.” *Machine Learning*, 54(1):45–66, 2004。
> 出处：Lukas Ruff, Robert A. Vandermeulen, Nico Görnitz, Lucas Deecke, Shoaib A. Siddiqui, Alexander Binder, Emmanuel Müller, Marius Kloft. “Deep One-Class Classification.” ICML, 2018。公开版实验为 MNIST、CIFAR-10 与 GTSRB 对抗样本，不是 MVTec。
> 出处：Karsten Roth, Latha Pemula, Joaquin Zepeda, Bernhard Schölkopf, Thomas Brox, Peter Gehler. “Towards Total Recall in Industrial Anomaly Detection.” CVPR, 2022。第 1–2 页将任务写成 cold-start industrial anomaly detection：训练只含正常图像，测试要图像级分数与像素热图。
> 出处：Chenyu Liu, Konstantinos Gryllias. “A Deep Support Vector Data Description Method for Anomaly Detection in Helicopters.” PHM Society European Conference, 2021，第 234–237 页。输入是 Airbus 直升机加速度计序列，不是光学表面图。

**[分析判断]** 同一种建模目标可以用于图像或振动信号，但输入、异常含义和评估方式仍需分别说明。本目录重点讨论光学工业图像。

## 2. 描述问题设定的六个维度

阅读论文时，按以下六个维度记录实验条件；论文未说明的条件应标为未明确。

### 2.1 训练时看见什么（监督协议）

| 协议 | 训练数据 | 工业上何时出现 |
|---|---|---|
| 无监督 / 冷启动 / 单类 | 只有正常样本 $\mathcal X_N=\{x:y=0\}$ | 本库默认；缺陷种类事先未知 |
| 半监督 | 正常 + 少量已标缺陷 | 返修数据开始积累之后 |
| 弱监督 | 图像级「有无缺陷」，无像素 | 只有抽检标签 |
| 全监督缺陷分类 | 缺陷类别集合固定且有标 | 固定类别的监督检测或分割；应与未知缺陷的识别任务区分 |

**[业界共识]** 工业论文里的 “unsupervised anomaly detection” 多数等于「只用好品」，不是聚类意义上的无监督。

**[论文发现]** PatchCore 的训练集只含正常图像，测试集含正常与异常，并同时要图像级与像素级输出。CVPR 2022 公开版第 1–3 页。

### 2.2 异常的语义类型

| 类型 | 含义 | 对方法的压力 |
|---|---|---|
| 结构异常 | 局部外观破损、污染、纹理断裂 | 局部特征 + 定位；PatchCore / 多数 MVTec 类别 |
| 逻辑异常 | 零件缺失、数量/位置关系错误、装错件 | 仅比较局部特征的最近邻距离可能不足；还需考虑关系或全局约束 |
| 语义上的分布外样本 | 整图变成另一个物体类 | CIFAR 式 OCC；**不是**产线划痕问题 |

**[分析判断]** 首批方法族串讲主要讨论结构异常，逻辑异常留待后续。评价方法时，应把结果限定在对应的异常类型和实验条件内。

### 2.3 输出

- 图像级：这张图像是否异常。
- 像素级 / 区域级：缺陷在哪。
- 两者都要：工业质检的常见需求。PatchCore 明确两者都报。CVPR 2022 公开版第 1、5 页。

### 2.4 样本预算

| 预算 | 含义 | 和本库方法族的关系 |
|---|---|---|
| 多样本正常 | 目标产品有一批正常图像，可建立记忆库或训练模型 | 记忆库、单类分类与密度建模的常见起点 |
| 少样本 | 新产品只有几张正常图像 | 后续主题：比较少量正常样本下的方法 |
| 零样本 | 目标产品没有好品图，只靠预训练 / 文本 | 视觉语言模型异常检测的设定之一；此处不使用目标适配集 |

### 2.5 域关系：正常变化与缺陷如何区分

**[分析判断]** 例如，同一零件在新光照下颜色变深，仍应判为正常；零件表面新增划痕，则应判为异常。适配需要处理前一种变化，同时保留识别后一种变化的能力。

| 域关系 | 训练 / 适配 | 测试 | 说明 |
|---|---|---|---|
| 同分布 | 该产品、该相机、该光照的好品 | 同一产品流 | 经典 MVTec 主表 |
| 同质偏移 | 源产品好品（可有标或仅正常）+ **目标好品适配集** | 目标产品 | 本库重点：利用确认正常的目标样本适配 |
| 无目标样本 | 多个源产品 | 未见过的新产品 | 领域泛化，安排在后续阶段 |
| 测试流在线更新 | 用当前测试批次更新统计量或参数 | 产线混合流 | 测试时适应；若将缺陷误当作正常样本更新，可能降低异常识别能力 |

**[分析判断]** 若只用目标产品的正常图像建立记忆库，且没有源域到目标域的迁移过程，可以先按目标域上的单类异常检测理解。若还利用其他产品或采集条件下的数据、模型或统计量进行适配，则需要同时说明源域与目标域的关系。

**[分析判断]** 本库评价适配方法时，同时关注正常样本的误报和异常样本的漏报。如果适配过程将缺陷特征也纳入正常样本的接受范围，域间差异即使减小，异常识别也可能变差。这属于迁移效果变差的风险，不能仅凭两个域的特征是否相似来判断方法有效。

### 2.6 本库重点讨论的设定

| 轴 | 取值 |
|---|---|
| 监督协议 | 冷启动：只有好品 |
| 异常类型 | 首批 = 结构异常；逻辑异常后续 |
| 输出 | 图像级 + 像素级 |
| 样本预算 | 首批 = 目标产品有一批确认正常的图 |
| 域关系 | 允许同质偏移；适配集应是 **确认正常** 的目标好品。领域泛化与测试时适应留待后续 |
| 模态 | 光学图像；振动信号仅作跨任务比较 |

## 3. 方法族总览：如何建模正常样本

**[分析判断]** 在相同问题设定下，各方法可以采用不同的正常样本模型。下表概括建模思路与需要检查的风险，不能代替具体论文的实验结论。

> Memory Bank（记忆库）：保存正常样本的参考特征，供测试时比较或检索。
>
> VAE（Variational Autoencoder，变分自编码器）：通过编码器近似潜变量后验，并用解码器描述数据生成过程的概率模型。
>
> ELBO（Evidence Lower Bound，证据下界）：对数边际似然的下界，常用作潜变量模型的训练目标。
>
> VLM（Vision-Language Model，视觉语言模型）：联合处理图像与文本表示的模型；本文用 VLM-AD 表示其在异常检测中的应用。

| 方法族 | 目录 | 建模假设概括 | 需要检查的风险 | 首批计划 |
|---|---|---|---|---|
| OCC / 超球体 | `OCC/` | 用超球体描述正常特征的接受范围 | 球形范围可能不足以描述复杂的正常分布；语义分类不能代替局部定位 | 是 |
| 特征记忆库与原型 | `Memory-Prototype/` | 正常局部特征可被有限样本（或原型）覆盖；用到正常参考特征的距离评分 | 局部比较忽略逻辑关系；特征提取器变化后参考特征失配；子集选择遗漏少见正常样本 | 是 |
| 特征空间合成 + 判别 | `Feature-Synthesis/` | 在特征里加噪声/合成异常，学一个可分边界 | 合成分布与真实缺陷有差异；分布偏移可能影响判别边界 | 是 |
| 学生–教师蒸馏 | `Distillation/` | 教师对正常的表示，学生学得会；异常处师生不一致 | 学生也能拟合异常处的教师输出，导致差异不足 | 是 |
| 归一化流 | `Normalizing-Flow/` | 正常可用可逆变换接到简单密度，以低似然作为异常线索 | 分布外样本也可能获得高似然 | 是 |
| VAE | `VAE/` | 用潜变量模型描述正常样本，以重构误差或 ELBO 构造分数 | 缺陷也可能被准确重构；ELBO 不等于精确似然 | 是 |
| VLM-AD | `VLM-AD/` | 语言–图像预训练提供「正常/缺陷」可迁移先验 | 细粒度工业纹理与自然语言对不齐；零样本 ≠ 已校准 | 是 |
| 其他自编码器或生成对抗重建方法 | （后续） | 正常可重构、异常不可 | 与 VAE 近，但不并进 VAE 族 | 否 |
| Mean Teacher | 不在本树 | 通过教师与学生预测的一致性利用未标注数据 | 见 `04-Domain-Adaptation/Mean-Teacher/`；`MT+AD` 后续只做链接 | 否 |

**[分析判断]** 比较密度建模方法时，应区分归一化流通过变量替换计算的似然，与 VAE 使用的 ELBO。比较记忆库方法时，则需要说明参考特征如何保存、如何计算距离。

视觉语言模型异常检测是后续需要补充原文与串讲的主题。相关基础见 [CLIP](../02-Vision-Tasks/clip.md)；开放词汇目标检测的阅读入口见 [视觉语言先验](../04-Domain-Adaptation/VLM-Prior/pointer.md)。

## 5. 读法

1. 按第 2 节记录实验条件，标出论文没有说明的部分。
2. 按第 3 节确定方法的建模假设，分析分布偏移会怎样影响正常与异常的区分。
3. 按 [学习路径](../learning-path.md)进入已有正文或论文原文；单篇笔记规范见 [阅读草稿说明](../agent/deepdive.md)。

若方法涉及源域到目标域的适配，同时阅读 [领域自适应总览](../04-Domain-Adaptation/problem-setting-and-overview.md)。需要分别说明如何迁移表示，以及如何用适配后的表示计算异常分数。
